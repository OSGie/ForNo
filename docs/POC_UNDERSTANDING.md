# تأكيد فهم نطاق PoC

المطلوب هو مشروع ويب واحد قابل للنشر يعرض رحلة بيع SaaS عربية احترافية لموفوتر. الأولوية لجودة الـLanding Page ووضوح الـUI/UX وتناسق الهوية، ثم لرحلة عملية قابلة للتجربة من تخصيص الشخصية إلى الباقة والـCheckout والدفع التجريبي والعقد ولوحة التحليلات المبسطة.

سيكون التتبع صحيحًا ومهيأً للترقية باستخدام UID وUTM وData Layer وملفات إعداد قابلة للاستبدال لـGTM وGA4 وMeta. لكن الربط الخارجي سيظل غير نشط في الـPoC، كما ستبقى نماذج الـExit-Intent والعقد محلية. لا توجد مدفوعات حقيقية، ولا تعقيدات إنتاجية مثل S3 أو PDF خادمي أو CRM أو جدولة أو استرداد أموال.
