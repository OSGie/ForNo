# نطاق PoC المعتمد

هذا المشروع هو **نموذج إثبات مفهوم قابل للنشر** لمسار مبيعات SaaS لموفوتر. وهو لا يمثل ربط دفع أو CRM أو تخزين إنتاجي حيًا. تتوفر كل نقطة اتصال مستقبلية كواجهة إعداد أو Adapter واضح، بينما تعمل النسخة الحالية ببيانات محلية وأحداث داخلية ومحاكاة دفع آمنة.

| متاح الآن | يؤجل للربط الإنتاجي |
|---|---|
| صفحات هبوط عربية RTL، تخصيص شخصية، باقات وCheckout | حساب PayTabs ومفاتيح الإنتاج ونداءات callback الحقيقية |
| UID وUTM وData Layer وأحداث محفوظة محليًا | GTM وGA4 وMeta بمعرفات أعمال حقيقية |
| صفحة دفع خارجية تجريبية واعتماد خادمي محلي | معاملـات مالية وبطاقات وRefunds |
| عقد HTML قابل للطباعة والتنزيل ونص قانوني حرفي | PDF خادمي وS3 وروابط موقعة ونسخ Google Drive |
| لوحة مؤشرات للمسار والأحداث | Attribution كامل وoutbox وعمليات مجدولة وCRM والبريد |

## معيار النجاح

ينجح النموذج عندما يمر الزائر عبر اختيار الشخصية والباقات وCheckout والدفع التجريبي والعقد، وترصد لوحة المؤشرات الرحلة ببيانات حقيقية من قاعدة المشروع، مع جودة واجهة احترافية متجاوبة وملتزمة بهوية موفوتر.
