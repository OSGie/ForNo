# مصفوفة تسليم PoC

| جزء التجربة | السلوك الذي سيجربه المستخدم | مصدر الحقيقة في الـPoC | حد النسخة |
|---|---|---|---|
| التخصيص | يختار مكتب محاسبة أو شركة، أو يصل مباشرة من رابط UTM | الذاكرة المحلية وسجل الحدث | لا توجد شرائح أو حملات حية. |
| السعر | يختار الباقة والفترة والإضافات ويرى VAT 14% | دالة تسعير خادمية بالأقراش | لا توجد فواتير ضريبية فعلية. |
| الدفع | يخرج إلى رابط تجريبي ثم يعود بعد نجاح محاكى | إجراء خادمي محلي يحدّث حالة الطلب | لا يوجد اتصال PayTabs أو بطاقة. |
| العقد | يرى نموذجًا بعد نجاح الطلب وينزل نسخة للطباعة | سجل العقد وHTML مدمج من المصدر القانوني | لا يوجد PDF/S3 أو توقيع إلكتروني. |
| التحليلات | يرى أحداث ومسارًا مختصرًا داخل اللوحة | EventLog محلي في قاعدة المشروع | لا يوجد إرسال إنتاجي إلى GTM/GA4/Meta. |
