# ملاحظات مرجع الفوتر

## الشريحتان 1–2

المرجع يستخدم خلفية بنفسجية موحّدة ونصًا أبيض، مع أعمدة واسعة تفصل بين التواصل المباشر والمتابعة الاجتماعية والروابط السريعة. يظهر عنوان قصير فوق كل عمود، وتأتي البيانات كسطور متباعدة بأيقونة صغيرة بمحاذاة كل سطر. يحتفظ الفوتر بمساحة بيضاء واسعة أسفل الأعمدة مع صف قانوني مركزي في الأسفل.

لا تُنقل عناصر المرجع أو أصوله البصرية نفسها؛ سيُنفَّذ الفوتر بهوية موفوتر الحالية ومكوّنات أصلية متجاوبة.
